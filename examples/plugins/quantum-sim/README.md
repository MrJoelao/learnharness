# Quantum Circuit Lab

An interactive quantum computing sandbox for gate simulation, superposition, and quantum entanglement.

### Capabilities
- **Single Qubit Gates**: X, Y, Z, Hadamard (H), Phase (S, T)
- **Multi-Qubit Entanglement**: Controlled-NOT (CNOT), SWAP, Toffoli
- **State Visualization**: Bloch Sphere 3D projection, State vector amplitude & phase bars
- **Measurement**: Probabilistic collapse and sampling distribution histogram
