# Graph & Pathfinding Visualizer

An interactive laboratory for graph traversal and shortest-path heuristics.

### Included Algorithms
- **Breadth-First Search (BFS)** and **Depth-First Search (DFS)**
- **Dijkstra's Algorithm** with priority queue state inspection
- **A\* Heuristic Search** with Euclidean and Manhattan metrics
- **Topological Sorting** (Kahn's algorithm & DFS-based cycle detection)

### Features
- Interactive node dragging and weight editing
- Step-by-step playback with pseudocode highlighting
- Step metrics: visited nodes, frontier size, path length
